# Capsule Tiled

Capsule Tiled imports Tiled maps into [Capsule Engine](https://github.com/just-awesome-games/capsule-engine) scenes at build time. Reference `JAG.Capsule.Tiled` beside `JAG.Capsule.Build` and save `.tmj` maps and `.tsj` tilesets under the logic project's `Assets/Scenes/`. Each map then becomes a scene document the game loads by name.

The [quick start](https://github.com/just-awesome-games/capsule-engine-tiled#quick-start) and the [Tiled subset](https://github.com/just-awesome-games/capsule-engine-tiled#tiled-subset) are in the repository README.

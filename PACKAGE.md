# Capsule Tiled

Tiled scene authoring for [Capsule Engine](https://github.com/just-awesome-games/capsule-engine). Reference `JAG.Capsule.Tiled` beside `JAG.Capsule.Build`, save `.tmj` maps and `.tsj` tilesets under the game's `asset-sources/scenes/`, and build: every map ships as a Capsule scene document the game loads by name. Nothing to configure, nothing to run by hand.

Start with the [repository quick start](https://github.com/just-awesome-games/capsule-engine-tiled#quick-start), which also lists the [Tiled subset](https://github.com/just-awesome-games/capsule-engine-tiled#tiled-subset) the importer accepts.
